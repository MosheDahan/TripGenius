# TripSpark Frontend

React and TypeScript client for TripSpark.

## Local development

Run `npm ci`, then `npm start`. The local API defaults to `http://localhost:4000/api`. Set `REACT_APP_API_URL` to override it.

## Build and tests

- Production build: `npm run build`.
- Tests: `npm test -- --watchAll=false`.

The complete application setup, Docker instructions, and API configuration are in the [project README](../TripSpark.md).
